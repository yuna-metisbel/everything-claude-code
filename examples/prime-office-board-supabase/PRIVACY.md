このファイルは、事務所ボードを導入した会社が**自社の文書として出すための下書き**。
〈 〉のところを自分の会社のものに書き換えて、「設定」タブの
**個人情報の取り扱い**に貼ると、スタッフも登録前に読めるようになる。

> 法律家が書いたものではない。個人情報保護法の項目に沿って、このボードが
> 実際に預かっているものを並べたもの。**出す前に一度、専門家に見てもらうこと。**
> とくに〈保存する期間〉と〈窓口〉は、会社の実情に合わせないと意味がない。

## 〈会社名〉 事務所ボード 個人情報の取り扱いについて

〈会社名〉（以下「当社」）は、スタッフ用の共有ボード「事務所ボード」で
お預かりする個人情報を、次のとおり取り扱います。

### 1. 何をお預かりするか

| 預かるもの | 誰のもの | 入れる人 | 見られる人 |
|------------|----------|----------|-----------|
| 氏名 | 本部メンバー、店舗スタッフ | 本人 | 本部、同じ店舗のスタッフ |
| メールアドレス | 本部メンバー | 本人 | 本部（ログインに使う） |
| 4桁の暗証番号 | 店舗スタッフ | 本人 | **本部（下の7を読んでください）** |
| 電話番号・緊急連絡先 | 本部メンバー | 本人 | **本部のみ** |
| 予定（事務所／在宅／外／休み、時間、連絡がつかない時間） | 本部メンバー | 本人・本部 | 本部 |
| 出退勤の時刻、働いた時間 | 店舗スタッフ | 本人（打刻） | 本部、同じ店舗のスタッフ |
| シフト（出勤・休み・未定と時間） | 店舗スタッフ | 本人・店長・本部 | 本部、同じ店舗のスタッフ |
| 鍵を開けた・閉めた記録、鍵を持っているか | 店舗スタッフ | 同じ店舗のスタッフ | 本部、同じ店舗のスタッフ |
| 事務所の鍵の開閉、備品の持ち出し | 本部メンバー | 本人 | 本部 |
| やることの担当・完了者・引き継ぎメモ | 本部メンバー、店舗スタッフ | 本人・ほかの人 | 範囲は項目ごとに設定 |
| 自分用のメモ・やること | 本部メンバー | 本人 | **本人と、本人が見せると決めた人だけ** |
| 支払いの相手先の名前、金額 | 取引先（個人事業主を含む） | 本部 | **本部のみ** |
| 媒体の ID・パスワード、キャスト名 | 店舗・キャスト | 本部 | 範囲は項目ごとに設定 |
| 通知を受け取る端末の識別子 | 本部メンバー | 本人（通知を入れたとき） | **本人のみ。本部も見られない** |
| ログインの失敗回数 | 店舗スタッフ | 自動 | 本部 |

本部メンバーと店舗スタッフは、**別のログイン**です。
店舗スタッフは本部の画面（支払い・媒体の ID とパスなど）を見られません。

### 2. 何のために使うか

- 事務所と店舗の予定・シフト・やることを共有し、引き継ぎの行き違いを防ぐため
- 勤怠と鍵の開閉を記録し、だれがいつ在店していたかを確認できるようにするため
- 連絡がつかないときや、急なことがあったときに連絡するため（緊急連絡先）
- 支払いの期日を管理するため
- 会議やお知らせ、期日が近いものを通知するため

これ以外の目的には使いません。本人の同意なく他の目的に使うことはしません。

### 3. どこに置いているか／誰に渡るか

当社は次の事業者を使っています。目的の達成に必要な範囲で取り扱いを委託します。

| 事業者 | 役割 | 置き場所 |

| Render Services, Inc.（米国） | 画面（静的サイト）の配信 | — |
| Google LLC（米国） | Android・Chrome への通知の配送、画面の書体の配信 | — |
| Apple Inc.（米国） | iPhone・Safari への通知の配送 | — |
| Mozilla Corporation（米国） | Firefox への通知の配送 | — |

データそのものは東京に置いていますが、**運営する会社はいずれも日本国外**です。
また、画面を開くたびに、書体と部品の配信元（Google、jsDelivr）に
**IP アドレスが渡ります**。これはページを表示するために避けられません。

通知を入れた端末については、通知の本文（会議の件名など）が
Google・Apple・Mozilla の通知サービスを経由して端末に届きます。

上記以外の第三者に個人情報を渡すことはありません。
法令に基づく開示の求めがあった場合を除きます。

### 4. どのくらい保存するか

〈ここを会社の実情に合わせて書き換えてください。〉

このボードは、**消すまで記録を残す**作りです。自動で消える仕組みはありません。
そのため、少なくとも次を決めて書いてください。

- 退職・契約終了のあと、氏名・電話番号・緊急連絡先をいつ消すか
  （例：契約終了から〈 〉か月後に消す）
- 勤怠と鍵の記録をいつまで残すか
  （労働に関する記録は、法律上の保存義務がある場合があります）
- 決めた期間が過ぎたものを、誰が、どうやって消すか

消す操作は本部が画面から行えます。スタッフを「利用停止」にすると
ログインできなくなりますが、**それだけでは記録は消えません**。

### 5. 本人からの求めについて

ご本人（または代理人）から、次の求めがあったときは、法令に従って対応します。

- 預かっている内容を見せてほしい（開示）
- 間違っているので直してほしい（訂正）
- 消してほしい（削除）
- 使うのをやめてほしい（利用停止）

窓口は下の 8 です。ご本人であることを確認したうえで、
原則として〈 〉営業日以内にお返事します。

### 6. 安全のためにしていること

- 画面のデータは、ログインした人の立場に応じてデータベース側で制限しています
  （店舗スタッフが本部の画面を見ようとしても、データが返りません）
- 電話番号・緊急連絡先、支払い、媒体の ID とパスは本部のみが見られます
- 自分用のメモは、本人が見せると決めた人以外には返りません
- 暗証番号を5回続けて間違えると、10分間ログインできなくなります
- 通知の宛先（端末の識別子）は本人以外、本部も見られません

**していないこと**も正直に書きます。

- 媒体の ID とパスワードは、**暗号化せずに保存**しています
  （本部だけが見られる前提の運用です）
- 4桁の暗証番号も暗号化していません。理由は次の 7 のとおりです

### 7. 4桁の暗証番号について

店舗スタッフの暗証番号は、**入力されたそのままの形で保存**しており、
**本部が見ることができます**。忘れた人に伝え直せるようにするためです。

4桁は組み合わせが1万通りしかなく、暗号化しても、記録を読める人が
総当たりで元に戻せます。「暗号化してあるから安全」と言えないため、
安全に見せかけずに、**本部が見られることをはっきり伝える**ことを選びました。

そのため、**ほかで使っている暗証番号やパスワードを使い回さないでください。**
登録の画面と変更の画面にも同じことを書いてあります。
