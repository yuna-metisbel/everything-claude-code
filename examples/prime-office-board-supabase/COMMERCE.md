# お金を取り始めるときに必要なもの（ひな形）

**無料で配っているあいだは、この文書は不要。** 読むのは課金を決めたとき。

〈 〉を埋めて使う。法律家・税理士が書いたものではないので、
**請求を始める前に一度は専門家に見てもらうこと。**

---

## 先に：特定商取引法は、たぶんかからない

よく「SaaS を売るなら特商法の表示が必要」と言われるが、
**特定商取引法の通信販売の規制は、事業者間の取引には原則かからない**
（特商法26条1項1号。相手が営業として結ぶ契約は適用除外）。

事務所ボードは会社の事務所で使うもので、売る相手は会社。
個人事業主の店舗が相手でも、事業のために契約するなら同じく対象外になる。

つまり**特商法表示そのものは、義務としては出てこない可能性が高い。**
ただし次の場合は変わるので、確認すること。

- 個人が、事業と関係なく買う形にするとき
- 一般向けに広く売る形（誰でもカードで申し込める導線）にするとき

迷うなら、載せておいて損はない。下の「任意で載せるなら」を使う。

## 義務として本当に出てくるもの

課金を始めたときに、特商法より先に効くのはこちら。

### 1. 請求書と、インボイス制度の登録番号

相手が消費税の仕入税額控除を受けるには、**適格請求書**が必要。
登録していないと、相手は払った消費税を控除できず、実質その分だけ高くつく。

- 適格請求書発行事業者の**登録番号**（T＋13桁）〈 〉
- 取引年月日、取引内容、税率ごとに区分した対価と消費税額
- 書類の交付を受ける事業者の名称

登録していない場合は、**その旨を先に伝える**こと。あとで揉める。

### 2. 消費税の扱い

- 価格は税込か税別か。**どちらで書くか決めて、統一する**〈 〉
- 総額表示（消費者向けのとき）

### 3. 継続課金にするときの条件

月額にするなら、ここを [TERMS.md](TERMS.md) に書き足す。

- 請求の締めと支払期日〈 〉
- 支払方法〈 〉
- 解約の申し出をいつまでにすれば、いつから止まるか〈 〉
- 解約したあと、データをいつまで保持して、いつ消すか〈 〉
  （[BACKUP.md](BACKUP.md) と揃える）
- 値上げするときの予告期間〈 〉

**解約したあとのデータの扱いは、いちばん揉める。**
「解約日に消す」のか「〈 〉日は置いて、書き出しを渡してから消す」のか、
先に決めて書くこと。

### 4. 無料から有料に変えるとき

いま無料で使ってもらっている1〜2社には、[TERMS.md](TERMS.md) 第2条のとおり
〈 〉日前までに知らせる。そのとき、その会社は断って使うのをやめられる。

断られたときにデータをどう渡すかは、TERMS.md 第7条のとおり。
**Supabase プロジェクトが導入先の名義（A）なら、何もしなくてもそのまま使える。**
提供側の名義（B）だと移行作業が必要になる——ここでも A が楽。

## 任意で載せるなら（特商法に準じた表示）

義務でなくても、申し込みページに置くと相手は安心する。

```text
■ 事業者名
〈会社名 / 屋号〉

■ 代表者
〈氏名〉

■ 所在地
〈住所〉

■ 連絡先
〈メールアドレス〉
〈電話番号〉（受付時間 〈 〉）

■ 適格請求書発行事業者 登録番号
〈T0000000000000〉（未登録の場合は「未登録」と書く）

■ 提供するもの
スタッフ用の共有ボード「事務所ボード」の利用と、導入時の設定

■ 料金
〈金額〉（税〈込/別〉） / 〈月額・年額〉
初期費用：〈金額 / なし〉

■ 料金以外に必要な費用
Supabase および画面の配信にかかる費用
（導入先の名義で契約する場合は導入先の負担）

■ 支払方法と時期
〈銀行振込 / 毎月末締め、翌月〈 〉日までに〉

■ 提供を開始する時期
〈入金確認後〈 〉営業日以内に設定を行い、利用開始〉

■ 解約について
〈 〉日前までにご連絡ください。〈 〉から停止します。
日割りの返金は〈行いません / 行います〉。

■ 動作環境
スマートフォンまたはパソコンの最新のブラウザ
（iPhone は Safari、Android は Chrome を推奨）
通知を使う場合、iPhone はホーム画面に追加する必要があります

■ 返品・キャンセル
役務の提供であるため、提供開始後の返品はお受けできません。
〈不具合により利用できない場合の扱いを書く〉
```

## 課金を始める前のチェック

- [ ] [TERMS.md](TERMS.md) に支払い・解約・値上げの条項を入れた
- [ ] 適格請求書発行事業者の登録をしたか、未登録であることを伝えた
- [ ] 価格を税込・税別のどちらで書くか決めて、全部そろえた
- [ ] 解約後のデータの保持期間を決めて、[BACKUP.md](BACKUP.md) と揃えた
- [ ] いま無料の会社に、いつから有料になるかを知らせた
- [ ] 専門家（税理士・必要なら弁護士）に一度見てもらった
