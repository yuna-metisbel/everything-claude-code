SixView 設定

6つのパネルに表示するサイトと、自動ログイン用の情報を設定します。パスワードは OS のキーチェーン（macOS Keychain / Windows 資格情報マネージャー）で暗号化して保存されます。

この環境では OS の安全な保存領域が使えないため、ID/パスワードは保存できません。

全体設定

この OS では自動起動を設定できません。

Telegram 連携（DMの通知と返信）

パネルの新着メッセージを Telegram に通知し、Telegram でその通知に「返信」すると、 そのお客様にそのまま送信されます。ボットのトークンはパスワードと同じく OS のキーチェーンに暗号化して保存され、設定ファイルには書き込まれません。

パネル

同じサイトの別アカウントを開きたいときは、そのパネルの「複製」を使ってください。 パネルごとにログイン状態が分かれているので、同じサイトに同時に別アカウントでログインできます。
