# SixView — 複数サイトを1画面にまとめて開くデスクトップアプリ

業務でよく使うサイト（Venry / えすたま / えきちか / エステランキング / ふーぺ / CTI など）を、
**アプリを1つ開くだけ**でまとめて表示するツールです。初期状態は 3列 × 2段 の6画面ですが、
設定画面でパネルを増やせます（最大12画面。8画面なら 4列 × 2段）。
Windows と macOS の両方で同じように動きます。

![レイアウト](docs/screenshot.png)

- パネルごとに**ログイン状態（Cookie）が独立**しているので、同時ログインしても混ざりません
- **同じサイトの別アカウント**を並べて開けます（パネルを「複製」するだけ）
- ID / パスワードを登録しておけば、**ログイン画面で自動入力**（任意で自動送信まで）
- パスワードは **OS のキーチェーン**（macOS: Keychain / Windows: 資格情報マネージャー）で暗号化して保存
- パネル単位で「シークレット（毎回ログアウト状態）」にもできます
- X（旧Twitter）のような **ID → 次へ → パスワード の2段階ログイン**にも対応
- パソコンの起動時に自動で開く設定つき

---

## 1. インストール手順

このアプリはまだ「ソースコードの状態」なので、**最初の1回だけ** 自分のパソコンでインストーラーを作ります。
2回目以降は普通のアプリと同じで、アイコンをダブルクリックするだけです。所要時間は10〜15分ほどです。

### 手順1: Node.js を入れる（初回のみ）

[https://nodejs.org](https://nodejs.org) を開き、**LTS** と書かれている方をダウンロードしてインストールします。
すでに入っている場合は飛ばして構いません。

### 手順2: このアプリのファイルを取ってくる

GitHub の [`claude/dazzling-mayer-stwiza` ブランチ](https://github.com/yuna-metisbel/everything-claude-code/tree/claude/dazzling-mayer-stwiza)
を開き、緑色の **Code** ボタン → **Download ZIP** を選びます。
ダウンロードした ZIP を展開し、分かりやすい場所（デスクトップなど）に置いてください。

### 手順3: インストーラーを作る

**Mac の場合** — 「ターミナル」を開いて、次を1行ずつ実行します。
`cd` と半角スペースを打ったあと、展開したフォルダの中の `tools/six-view` を
Finder からターミナルの窓にドラッグ＆ドロップすると、パスが自動で入ります。

```bash
cd <ここに tools/six-view をドラッグ＆ドロップ>
npm install
npm run dist:mac
```

**Windows の場合** — まず ZIP を**展開（解凍）**します。エクスプローラーは ZIP をフォルダのように
開いて見せますが、展開しないと中身は使えません。パスに `.zip` が入っていたら展開できていない印です
（`cd : Cannot find path ...` というエラーになります）。

ZIP を右クリック →「**すべて展開**」。または PowerShell に次を貼り付けると、展開からフォルダ移動まで
一度に済みます（デスクトップに ZIP がある場合）。

```powershell
cd ([Environment]::GetFolderPath('Desktop'))
Expand-Archive .\everything-claude-code-claude-dazzling-mayer-stwiza.zip -DestinationPath .\sixview-src -Force
cd (Get-ChildItem .\sixview-src -Recurse -Directory -Filter six-view | Select-Object -First 1).FullName
```

手で展開した場合は、パスを調べる手間を省くためエクスプローラーから PowerShell を開きます。

1. エクスプローラーで、展開したフォルダの中の `tools` → `six-view` フォルダを開く
2. 上のアドレスバー（パスが出ている帯）をクリックして、`powershell` と打って Enter

これで、そのフォルダにいる状態の PowerShell が開くので `cd` は不要です。あとは次を1行ずつ実行します。

```powershell
npm install
npm run dist:win
```

パスを直接打ちたい場合は、たいてい次の形になります（`ユーザー名` はご自身のもの）。

```text
C:\Users\ユーザー名\Downloads\everything-claude-code-claude-dazzling-mayer-stwiza\tools\six-view
```

ZIP を「すべて展開」すると、**同じ名前のフォルダが二重**になっていることがあります
（`everything-claude-code-...\everything-claude-code-...\tools\six-view`）。
その場合は奥の方が正しいパスです。フォルダを開いて `tools` が見える階層が目印です。

`npm install` は数分かかります。終わったら `tools/six-view/dist` フォルダが出来ています。

### 手順4: インストールする

`dist` フォルダの中身をダブルクリックします。

| OS | ファイル | やること |
|----|----------|----------|
| Mac | `SixView-1.0.0-arm64.dmg`（Intel Mac は `-x64`） | 開いて SixView を Applications フォルダにドラッグ |
| Windows | `SixView Setup 1.0.0.exe` | 実行してインストール（`SixView 1.0.0.exe` はインストール不要のポータブル版） |

**初回起動時の警告について** — 署名なしで作ったアプリなので、1回目だけ警告が出ます。

- Mac: アプリを右クリック →「開く」→ もう一度「開く」。
  それでも駄目なら **システム設定 → プライバシーとセキュリティ** の下の方に出る「このまま開く」を押します。
- Windows: 「WindowsによってPCが保護されました」と出たら **詳細情報 → 実行**。

これ以降は、Launchpad（Mac）やスタートメニュー（Windows）から普通に開けます。
設定画面の「パソコンの起動時に SixView を自動で開く」をオンにしておくと、電源を入れるだけで6画面が出ます。

## 4. 設定画面でできること

| 項目 | 説明 |
|------|------|
| 表示名 | パネル左上に出る名前 |
| ログインページ URL | パネルが最初に開くページ（`https://` から入力） |
| シークレット | オンにすると毎回ログアウト状態で開きます |
| 拡大率 | そのパネルだけの表示倍率。`0` で全体設定に従う |
| 自動ログイン | 下記を参照 |
| ユーザーエージェント | 「対応していないブラウザです」と言われる場合だけ設定 |
| ログイン ID / パスワード | 保存すると自動ログインに使われます |
| 起動時に自動で開く | パソコンを立ち上げると SixView が自動起動します |

### 自動ログインの設定手順

**やることは ID とパスワードの登録だけです。**

1. **設定** を開き、そのパネルの **ログイン ID / パスワード** を入力して「認証情報を保存」
2. 「保存して反映」を押す

これだけで、次にそのサイトのログイン画面が出たときに自動で入力されます。
セレクタ（入力欄の指定）は**空欄のままで構いません** — パスワード欄と、その直前にある入力欄を
自動で探して入れます。検索ボックスのような「ログイン画面ではない入力欄」には入りません。

> 以前のバージョンで作った設定は「自動入力する」がオフのままになっていることがあります。
> その場合は設定画面の上の方にある **「すべてのパネルで自動ログインをオンにする」** を押してから保存してください。

うまく入らないサイトだけ、次の手順でセレクタを覚えさせます。

1. そのサイトの **ログイン画面をパネルに表示** しておく（ログアウト状態にする）
2. そのパネルの **自動ログイン** を開いて **「ログイン欄を自動検出」** を押す

![自動ログインの設定](docs/settings.png)

これで次回以降、そのサイトのログイン画面を開くと自動で入力されます。
送信ボタンまで押してほしい場合は「入力後にログインボタンも押す」をオンにしてください。

それでも駄目なときだけ、セレクタを手入力します。パネル上で右クリック →
「検証」（または メニューの **表示 → 開発者ツール**）で入力欄を選び、`id` や `name` を確認してください。
よくある例:

| サイトの作り | セレクタの書き方 |
|--------------|------------------|
| `<input id="login_id">` | `#login_id` |
| `<input name="account">` | `input[name="account"]` |
| パスワード欄全般 | `input[type="password"]` |
| ログインボタン | `button[type="submit"]` |

- **ログインページの判定**: URL に含まれる文字列（例 `login`）。空欄ならそのサイトの全ページで試します。
  `/regex/i` の形式で正規表現も書けます。
- **入力後にログインボタンも押す**: オンにすると送信まで自動で行います。
  まずはオフで「入力されるか」を確認してからオンにするのが安全です。
- **入力までの待機 (ms)**: 画面の描画が遅いサイトでは `1000` くらいに増やしてください。

### 自動ログインが効かないとき

| 症状 | 対処 |
|------|------|
| 何も入力されない | まず「自動入力する」がオンか、ID / パスワードが「保存済み」になっているか確認。次にログイン画面を表示した状態で「ログイン欄を自動検出」 |
| 「パネルがまだ読み込まれていません」と出る | そのパネルにページが表示されてから検出してください |
| 「パスワード欄が見つかりません」と出る | すでにログイン済みの可能性。`⎋` でログイン状態を消してから再検出 |
| 途中まで入力されて消える | 「入力までの待機」を長くする |
| 二要素認証がある | 自動送信をオフにして、コードだけ手入力してください |
| ログインが毎回切れる | そのパネルの「シークレット」がオンになっていないか確認 |

## 5. 02View — 02 のアカウントを8つ並べるもう1つのアプリ

同じソースから、**02 専用のアプリ**も作れます。業務6サイトの SixView とは別のアイコン・別の設定領域に
なるので、両方を同時に開いておけます。

最初から次の9画面（3列 × 3段）が入っています。

| # | パネル | URL |
|---|--------|-----|
| 1 | 02 店舗 | `https://m-sns.net/shop/login/` |
| 2〜8 | 02 キャスト1 〜 キャスト7 | `https://m-sns.net/cast/login/` |
| 9 | X | `https://x.com/login` |

キャスト用の7つは同じ URL ですが、**パネルごとにログイン状態が分かれている**ので、それぞれ別アカウントで
ログインできます。数を増やしたいときはそのパネルの「複製」、減らしたいときは「削除」を使ってください。

### 02View の作り方

SixView と同じフォルダで、コマンドだけ変えて実行します。

```bash
# macOS
npm run dist:mac:02

# Windows
npm run dist:win:02
```

できあがりは `dist-02` フォルダです（SixView は `dist` フォルダ）。インストール方法は同じです。

| OS | ファイル |
|----|----------|
| Mac | `02View-1.0.0-arm64.dmg`（Intel Mac は `-x64`） |
| Windows | `02View Setup 1.0.0.exe` |

設定やパスワードは SixView とは別に保存されます。

| OS | 場所 |
|----|------|
| Windows | `%APPDATA%\02View\` |
| macOS | `~/Library/Application Support/02View/` |

## 6. パネルを増やす・同じサイトに別アカウントで入る

設定画面の「パネル」欄で増減できます（1〜12画面）。

| やりたいこと | 操作 |
|--------------|------|
| 画面を増やす | 「パネルを追加」→ 表示名と URL を入力 |
| 同じサイトの別アカウントを開く | そのパネルの「**複製**」→ 表示名を変えて、別アカウントの ID/パスワードを保存 |
| 画面を減らす | そのパネルの「削除」 |
| 並べ方を変える | 「横に並べる数」で 2〜5列を指定（自動なら6画面は3列、8画面は4列） |

変更は「**保存して反映**」を押すと反映されます。

**同じサイトに複数アカウントで入れる理由** — パネルごとに Cookie の保存場所が分かれているためです。
「複製」すると別の保存場所が割り当てられるので、同じ URL でもアカウントが混ざりません。
ブラウザのプロファイルを分けているのと同じ状態になります。

> 削除したパネルに保存していた ID / パスワードも一緒に消えます。戻したいときは入力し直してください。
>
> パネル1つにつきブラウザ1つ分のメモリを使います。8画面以上にするとメモリ使用量が増えるので、
> 動作が重いときは画面数を減らすか、使わないパネルの拡大率を下げてください。

### X（旧Twitter）など、2段階ログインのサイト

X は「ユーザー名を入れて次へ → パスワード」の2画面に分かれています。SixView はこの形式に対応していますが、
セレクタの設定だけ**2回に分けて検出**する必要があります。

1. パネルに X のログイン画面（ユーザー名の入力欄）を表示 → 設定 →「ログイン欄を自動検出」
   → ID 欄が設定されます（「次の画面でもう一度」と表示されます）
2. パネルで「次へ」を押してパスワード画面にする → もう一度「ログイン欄を自動検出」
   → パスワード欄が追加されます
3. ID / パスワードを保存して「保存して反映」

以降は、ID 入力 → 次へ → パスワード入力まで自動で進みます。

> **認証アプリや SMS の確認コードが必要な場合**、そこから先は手入力になります。
> また X は見慣れない操作を検知するとコード確認を挟むことがあります。
> 一度ログインすれば Cookie が保持されるので、普段は自動ログインなしでも開いたままになります。

## 7. DM を Telegram で受け取って、Telegram から返信する

02 に新着メッセージが来たら Telegram に通知し、**Telegram でその通知に返信すると、そのお客様にそのまま送信されます**。

02 の LINE 通知は一方通行（届くだけ）なので、返信までやるにはこちらを使います。
サーバーは不要で、02View が起動している間だけ動きます。

### 7-1. 先に知っておいてほしいこと

- 自動操作が **02 の利用規約に触れる可能性**があります。アカウント停止のリスクはゼロではありません。使う前に規約を確認してください。
- お客様のメッセージ本文が **Telegram のサーバーを経由**します。
- **02View を閉じている間は動きません。**
- 02 の画面構成が変わると止まります。そのときは 7-4 をやり直してください。

### 7-2. Telegram のボットを作る

1. Telegram で `@BotFather` を開いて `/newbot` を送る
2. 名前を決めると **トークン**（`123456789:AA...` のような文字列）が発行される
3. 作られたボットを開いて、何でもいいので一言送る（これをしないと通知が届きません）

トークンは**パスワードと同じ扱い**です。人に見せない・チャットに貼らないでください。
漏れてしまったら `@BotFather` の `/revoke` で作り直せます。

### 7-3. 02View に登録する

設定画面の「Telegram 連携」で、

1. トークンを貼って「トークンを保存」
2. 「接続テスト」を押す → ボットの名前が出れば OK
3. **Telegram でそのボットに何か一言送ってから**「ID を取得」を押す → チャット ID が自動で入ります
4. もう一度「接続テスト」→ Telegram にテストメッセージが届けば完了
5. 「Telegram 連携を使う」にチェック

「ID を取得」で `まだボットにメッセージが届いていません` と出たら、手順3の一言が送れていません。
Telegram でボットを開いて「開始」を押してから、もう一度送ってください。

トークンは OS のキーチェーンに暗号化して保存され、設定ファイルには書き込まれません。

### 7-4. どこを見るかを教える（パネルごと）

プログラムは画面の「どこがメッセージ一覧か」を知りません。
**まずは自動でさがさせて、だめだった欄だけ手で教えます。**

#### まず「自動でさがす」

1. パネルに 02 の**メッセージ一覧**を表示する
2. 設定画面 → そのパネルのカード → **「DM の通知と返信」** を開く
3. **「自動でさがす」** を押す → 一覧の欄が埋まります
4. パネルで**会話を1つ開く**
5. もう一度 **「自動でさがす」** を押す → 返信の欄が埋まります

読み取るだけなので、この操作でメッセージが送られたり既読になったりすることはありません。
見つけた内容（先頭のお客様の名前と本文）がその場に表示されるので、合っているか確かめられます。

埋まらなかった欄があったら、その欄だけ下の手順で指定してください。
すでに入っている欄が上書きされることはありません。

#### 手で教える（埋まらなかった欄だけ）

パネルに 02 のメッセージ一覧を表示してから、設定画面の「DM の通知と返信」を開いて、

| 指定するもの | クリックする場所 |
|--------------|------------------|
| 1件の行（必須） | 一覧の中の、お客様1人ぶんの行 |
| 相手の名前 | その行の中の名前 |
| メッセージ本文 | その行の中の本文 |
| 未読バッジ | その行の赤い数字 |
| DM を開くボタン | 画面下のメニューの「DM」 |

「指定」を押すとパネルの上が桃色の枠で追えるようになるので、目的の場所をクリックします。中止は `Esc` です。

**「1件の行」を最初に指定してください。** 名前・本文・未読は、その行を基準に記録されます。

続けて、**会話を1つ開いた画面**にしてから、

| 指定するもの | クリックする場所 |
|--------------|------------------|
| 返信の入力欄（返信に必須） | メッセージを書く欄 |
| 送信ボタン | 送信ボタン |
| 一覧に戻るボタン | 戻る |

最後に「このパネルの新着メッセージを監視する」にチェックを入れて、「保存して反映」。

うまく指定できたかは **「今すぐ読み取ってみる」** で確認できます。
読み取れた件数と、先頭のお客様の名前・本文が表示されれば成功です。

### 7-5. 使い方

- 新着があると Telegram に `[02 キャスト1] たなか` のように、**どのアカウントの誰か**が分かる形で届きます。
- 返信するときは、その通知を**「リプライ」して**書いてください。普通に送っても 02 には届きません（宛先が分からないため）。
- 初期設定では、送信前に PC 側で確認ダイアログが出ます。慣れたら設定でオフにできます。
- 送信できたかどうかは Telegram に返事が来ます。

アプリを起動した直後の1回目は、**溜まっている分をまとめて通知しない**ように、黙って現状を記録するだけです。通知は2回目以降の変化から始まります。

## 8. ブーストのボタンを自動で押す

ブースト（順位を上げるボタン）を、**押せる状態になったら自動で押します**。
時間が来ていないときは何もしません。パネルごとに設定します。

### 8-1. 先に知っておいてほしいこと

- 7-1 と同じで、自動操作が**サイトの利用規約に触れる可能性**があります。使う前に確認してください。
- **アプリを閉じている間は押しません。** そのパネルにログインした状態で開いたままにしておく必要があります。
- 押せるかどうかはサイトの表示で判断します。ボタンが灰色・「あと○分」などになっているときは押しません。

### 8-2. 設定する

1. そのパネルに、**ブーストのボタンがある画面**を表示する
2. **設定** → そのパネルのカード → **「ブーストの自動クリック」** を開く
3. **「自動でさがす」** を押す
   （さがすだけです。この操作でブーストが押されることはありません）
4. **「ブーストのボタンを自動で押す」** にチェック
5. **保存して反映**
6. **「今すぐ押してみる」** で動くか確かめる

3 で見つからなかったときだけ、「指定」を押して、パネルの中のブーストのボタンを直接クリックしてください。
こちらも、クリックでブーストが押されることはありません。

### 8-3. 数字の意味

| 項目 | 既定 | 意味 |
|------|------|------|
| 確認する間隔（分） | 10 | 何分おきにボタンを見に行くか |
| 連続で押さない間隔（分） | 60 | 前に押してから最低これだけ空ける |
| 押す時間帯（開始 / 終了） | 0 / 24 | この時間帯だけ押す。`10` と `24` なら朝10時〜深夜 |

- 「押す時間帯」は 0〜24 で指定します。`22` と `6` のように**日をまたぐ指定**もできます。
- 開始と終了が同じなら 24 時間いつでも押します。
- 「連続で押さない間隔」は、**ボタンが常に押せるように見えるサイト**で押しすぎないための歯止めです。

### 8-4. 使い方

- 押したら Telegram に `[02 キャスト1] ブーストを押しました。` と届きます（不要ならチェックを外してください）。
- 「今すぐ押してみる」でも、**サイトがまだ押させてくれない状態なら押しません**。時間帯と「連続で押さない間隔」だけを無視します。
- ボタンの場所が変わったら、「自動でさがす」をもう一度押してください。

## 10. パネルのボタン

| ボタン | 動作 |
|--------|------|
| `‹` `›` | 戻る / 進む |
| `⟳` | 再読み込み |
| `⌂` | 設定したトップページへ戻る |
| 鍵マーク | 自動ログインを今すぐ実行 |
| `−` `＋` | 表示を縮小 / 拡大 |
| `⤢` | このパネルだけ全画面表示 / 元に戻す |
| 右上向き矢印 | 今のページを既定のブラウザで開く |
| `⎋` | このパネルのログイン状態（Cookie）を消す＝ログアウト |
| `☆` | 今開いているページを、このパネルの最初のページとして保存 |
| `✕` | **このパネルを閉じる**（設定・ログイン状態は残ります） |

### 開くページを変える

パネル上部に出ている**アドレス（URL）をクリックすると入力欄になります**。
別の住所を入れて `Enter` を押すと、そのパネルだけそのページに移動します（`Esc` で取り消し）。

これは一時的な移動なので、`⌂` を押せば元のページに戻ります。
**このページをこのパネルの定位置にしたい**ときは `☆` を押してください。次回の起動からそのページで開きます。

### パネルを閉じる・戻す

`✕` を押すとそのパネルが画面から消え、画面上部に「**閉じているパネル**」として名前が並びます。
その名前をクリックすればいつでも戻せます。

- 閉じても、**設定・保存したID/パスワード・ログイン状態は消えません**
- 残りのパネルで自動的に並べ直します（8枚 → 1枚閉じて7枚なら 4列 → 4列）
- 閉じたパネルはメモリを使わなくなるので、動作が重いときにも有効です
- 閉じた状態は保存されるので、次に起動したときも閉じたままです
- 設定画面の「**このパネルを表示する**」のチェックでも同じ操作ができます

### 閉じたパネルを別のサイト用に使う

名前の横の「**別のサイト**」を押すと、その枠を**別のサイトのパネルとして開き直せます**。
表示名と URL を入れて「開く」を押すだけです。

- 「**前のサイトのログイン情報と DM 設定を消す**」は、**チェックしたままにしてください**
  （前のサイトのパスワードや DM の位置指定が残っていると、別のサイトで誤って使われます）
- 同じサイトの URL が変わっただけのときは、このチェックを**外す**と、
  保存した ID/パスワードと DM の設定をそのまま引き継げます
- 開き直したパネルは、元の並び順のところに戻ります

## 11. 設定ファイルの場所

設定画面の左下に表示されているパスに `config.json` と `credentials.json` があります。

| OS | 場所 |
|----|------|
| Windows | `%APPDATA%\SixView\` |
| macOS | `~/Library/Application Support/SixView/` |

- `config.json` … サイトの URL やセレクタ（パスワードは入っていません）
- `credentials.json` … OS のキーチェーンで暗号化された ID / パスワード

`sites.example.json` は初期状態と同じ内容です。設定を作り直したいときは、これを `config.json`
としてコピーしてからアプリを起動してください。
別の PC へ移すときは `config.json` だけをコピーしてください
（`credentials.json` はその PC でしか復号できないため、パスワードは移行先で入れ直します）。

## 12. セキュリティについて

- パスワードは平文でファイルに書き込みません。OS の暗号化領域（macOS Keychain / Windows DPAPI）を使います。
- キーチェーンが使えない環境では**保存を拒否**し、画面上部に警告を表示します。この場合は Cookie によるログイン保持のみ使えます。
- パスワードは常にメインプロセスからログイン画面へ直接入力され、画面側のコードには渡していません。
- 各パネルは Node.js 権限なしの状態で動作します（`nodeIntegration` 無効・`contextIsolation` 有効）。
- 共有 PC では「シークレット」を使うか、終了前に `⎋` でログイン状態を消してください。

## 13. 開発

```bash
npm start                      # SixView として起動
npm run start:02               # 02View として起動（設定は別に保存されます）
npm run icon                   # assets/icon.png と icon-02.png を作り直す
node ../../tests/tools/six-view.test.js   # ユニットテスト
```

2つのアプリは同じソースです。どちらとして動くかは `src/lib/config-schema.js` の `BRANDS` で決まり、
ビルド時は `electron-builder.02.json` の `extraMetadata.sixviewBrand` で切り替えています。
アプリ名が違えば OS が設定の保存先を分けるため、設定・Cookie・パスワードは混ざりません。

ファイル構成:

```text
src/
  main.js              メインプロセス（ウィンドウ・パネル制御・自動ログイン実行）
  menu.js              アプリメニューとショートカット
  preload.js           画面とメインの受け渡し（パスワードは通しません）
  lib/
    config-schema.js   設定の既定値と正規化（Electron 非依存 = テスト可能）
    config-store.js    config.json の読み書き
    secret-store.js    キーチェーンを使った認証情報の保管
    autofill.js        ログイン自動入力スクリプトの生成
  renderer/
    index.html/.css/.js     6分割グリッド画面
    settings.html/.css/.js  設定画面
```
